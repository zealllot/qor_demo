# qor_demo

Minimal QOR Admin demo wired to Postgres. Used as a real-world fixture for [PRoctor](https://github.com/zealllot/proctor) — an AI-driven PR test runner — because it represents an awkward shape PRoctor needs to handle: pre-modules Go (no `go.mod`, expects `$GOPATH/src/github.com/zealllot/qor_demo` layout) backed by Postgres via `docker-compose`.

## Stack

- Go (GOPATH-era; `qor` v1 reads its template path from `$GOPATH` at runtime)
- [QOR Admin](https://github.com/qor/admin)
- [GORM](https://github.com/jinzhu/gorm)
- Postgres (docker-compose, host port `9722`)

## Run locally

```bash
git clone https://github.com/zealllot/qor_demo
cd qor_demo

# Bring up Postgres
docker compose up -d

# Source the env file (DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME)
set -a; . ./env; set +a

# Initialize go.mod once (this repo is GOPATH-era)
go mod init github.com/zealllot/qor_demo
go mod tidy

# Start the server
go run .
```

Visit <http://127.0.0.1:8080/admin>.

## PRoctor integration

`.pr-test.yml` and `.github/workflows/proctor.yml` were generated by [`/proctor-init`](https://github.com/zealllot/proctor) and pinned to PRoctor `v0.2.12`. On every PR push, PRoctor analyzes the diff, plans tests, runs them against this stack, and posts a report comment.
